# Bump typography

The accepted navigation and scene lettering keep EB Garamond. Editorial chapter
content and service dialogs use IM FELL English Regular and its genuine Italic,
by Igino Marini. Both local TrueType files preserve all original glyphs,
including French accents, œ and typographic apostrophes. No synthetic bold,
italic slant or texture filter is applied.

Source: https://github.com/google/fonts/tree/main/ofl/imfellenglish
License: IM-FELL-English-OFL.txt (SIL Open Font License 1.1).

The fonts are served locally; the website makes no requests to Google Fonts.
