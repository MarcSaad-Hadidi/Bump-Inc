# Integration Core — Figure, original construction

## Concept fixed before geometry (24 October 2026)

A five-port bench docking station brings existing enterprise tools onto one common mechanical bus. Five tool cartridges sit on fixed shallow cradles. Their interface collars first align sideways on saddle pads; then the cartridges move physically toward the bus and their conductive plugs enter the open adapter frames. All five engraved indicators move together and signals travel in parallel, before the single coordination rotor settles. This explains interoperability, not sequential request processing.

Desktop is a compact, long station (760 × 300 drawing), not a new page chapter. Mobile is a newly laid out two-row dock around a shorter bus, with three rear cartridges and two front cartridges (380 × 390 drawing); it is not a scale of the desktop model. No request capsule, assembly rail, security enclosure, dashboard or copied gallery object is used.

## Motion and geometry contract

The cartridge body, lid and stem share a twelve-unit insertion travel. Each adapter frame moves four units sideways over a wide saddle pad. The final stem ends on its matching fixed port face; the gap between the adapter jaws is larger than the conductive stem. All five cartridges insert simultaneously. Signals run together after all connectors are seated.

Five finite states: separate systems; adapter alignment; connector insertion; synchronized exchange; unified ecosystem. Reduced motion opens in the static final state and keeps direct step controls. A single GSAP timeline is visible-triggered and pauses outside the viewport or in a hidden document. Reentry starts a fresh finite demonstration. It never captures the wheel or pins the page.

All geometry and 321 projected paths for each indicator are precomputed once. Runtime writes transforms, opacity and existing indicator paths. A small painter-order function sorts 57 numeric keys and moves only DOM nodes whose audited order changes; it performs no geometry generation and no per-frame React render.
