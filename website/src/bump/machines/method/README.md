## Root controller contract

```tsx
<MethodWorkshop
  id="notre-methode"
  active={methodSectionIsActive}
  onController={(controller) => registerMethodGestureOwner(controller)}
/>
```

`onController` receives a stable object on mount and `null` on unmount:

```ts
interface MethodWorkshopController {
  goTo(index: number, options?: { immediate?: boolean }): boolean;
  getStage(): 0 | 1 | 2 | 3 | 4;
  getBusy(): boolean;
  finish(): void;
  setActive(active: boolean): void;
  isActive(): boolean;
}
```

`goTo()` returns false when busy or when the requested stage is already selected. No queued steps, wheel listeners, Observer instance, touch capture or global keyboard handlers are installed here. Root owns the single GSAP Observer / assisted-scroll gesture path and should consume one gesture only while this controller is active. At 0 + upward or 4 + downward, hand the gesture back to normal section navigation. Busy gestures should be consumed without queuing. `getStage()` reports the selected target immediately; `getBusy()` remains true until the finite transition finishes. Direct buttons and local keyboard use the same API.

`finish()` immediately lands at the selected state. It is useful before external section jumps or resizing. `setActive(false)` pauses the active transition and `setActive(true)` resumes it. IntersectionObserver and `document.visibilitychange` also gate playback. Reduced motion seeks the selected state immediately. React renders happen only when stage/busy/compact status changes; GSAP writes transforms and a few SVG attributes while moving. There is no idle tour, automatic step progression, per-frame React state or permanent RAF loop.

Root QA hooks: `data-method-stage="0..4"`, `data-method-busy="true|false"`, `data-method-time`, `data-method-compact`, `data-item="project.cassette"`.

## Layout

The component includes the required title, a short introduction, a large SVG figure, short active-stage copy, previous/next controls and five direct-step buttons. `showHeader={false}` hides its visible heading if the retained parent already owns the exact same title. Avoid retaining duplicate old method content.

The default section is `min-height:100svh`. Its own top padding clears navigation. `--method-nav-clearance` is 74px desktop / 75px mobile; root may override it on the component when the retained floating navigation requires more room. No modifications are needed to the existing painter/pencil opening.

Phones use a separate projection, a shorter/deeper bed, longer cross-slide, relocated gauge and a rear parts fixture. They are not a scaled desktop scene. At 390×844 and 320×740 all five stage controls remain inside one viewport. The stage explanation becomes a short block under the drawing with adjacent 43px controls. Touch scroll remains native; root may choose not to capture mobile vertical gestures.

## Mechanics and palette

One green project cassette, ivory insert and brass datum stay visible through all five states. Audit lowers a genuine clipped measuring stem onto a cartridge; analysis separates the cartridges along real guides; proposition moves a pen along the exact path being drawn; implantation grips the stored frame, lifts it above all instruments, transfers and lowers it, then closes hold-downs; maintenance engages a calibration key and turns the handwheel once before the gauge settles. The same finite GSAP master timeline plays backwards for reverse travel.

Four-tone surfaces are generated by Anatomy and assigned beige, ivory, deep green, steel, brass and ink material ramps. Red-orange is limited to the analogue needle. There are no gradients, extra dashboards, WebGL layers or decorative particle loops.

`audit.mjs --settle` uses official `A.recorder`, `A.settle`, `A.audit`, `A.report` and `A.failures` on the exact rendered shapes and returns a failing exit code for a genuine problem. Only the four actual foot pads are ground. The resulting measured keys are stored per resting pose in `depth-keys.ts`; runtime interpolates the measured biases while sorting the translated parts. The audit has no blanket ownership exclusions, proxy shapes or suppressed errors.

Evidence files are `audit-results.json`, `audit-results-compact.json`, `audit-motion-results.json`, `line-results.json`, `motion-results.json`, `quick-qa-results.json`, and PNGs in `shots/`.
